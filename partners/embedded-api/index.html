From consent to recovery.

When a user pursues a claim, CollectRefund’s managed recovery process takes over. We handle the documentation, state submission, follow-up, and payment.

    Consent & Search

    A mobile number begins the search inside your product or the hosted flow.

  2. 02

    Identity confirmation

    Before any match details are shown, the user confirms their identity, protecting their data and yours.

  3. 03

    Possible claims appear

    The user sees how many possible claims were found and a representative aggregate value.

  4. 04

    Recovery and monitoring

    If the user pursues recovery, CollectRefund manages the claim. Monitoring enrollment keeps watching for new matches.

Consent first, identity confirmed, data minimized.

Users consent before a search runs, and identity confirmation is required before match details are shown. Partners receive only the data their integration model requires, never a user’s full claim file.

Family monitoring, coming soon

Monitoring for funds tied to a user’s family members is in development and will be announced to partners when it is live.

Standard OAuth2, no surprises.

Partner integrations authenticate with OAuth2 client credentials: your service exchanges its credentials for a short-lived access token and calls the API server-to-server.

API documentation, endpoints, schemas, and integration guides are shared with approved partners after a request-access review. No live endpoints or credentials are published here.

Pricing.

Partnership pricing, recovery fees, and any commercial or revenue-sharing terms are established in the applicable partner agreement.

Integration questions, answered

What integration models does CollectRefund Embedded support?

A direct API, a hosted flow, referral handoff, white-label, and co-branded experiences. Partners choose the model that fits their product and compliance needs.

Where does CollectRefund Embedded work today?

CollectRefund Embedded currently supports All 50 states. CollectRefund Monitoring covers All 50 states.

How is user privacy and consent handled?

Users consent to the search before it runs, and identity confirmation is required before match details are shown. Partners never receive more personal data than the integration model requires.

What does an embedded partnership cost?

Partnership pricing, recovery fees, and any commercial or revenue-sharing terms are established in the applicable partner agreement.

How do we get the API documentation?

API documentation is shared with approved partners. Request access with a short description of your product and use case, and the partnerships team will follow up.
